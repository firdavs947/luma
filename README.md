# LUMA

Мультимедийное приложение (музыка, фильмы, аниме) для iOS и Android на Flutter.

Документ описывает загрузку и использование музыкальных файлов в приложении:
поддерживаемые форматы, порядок добавления трека, работу плеера, проверки
безопасности и внутреннее устройство конвейера импорта.

---

## 1. Загрузка музыки в библиотеку

### 1.1. Как добавить трек (для пользователя)

1. Откройте раздел **Библиотека** и перейдите на вкладку **Загрузки**.
2. Нажмите **Добавить аудиофайл** — откроется системный выбор файла с фильтром
   по поддерживаемым форматам.
3. Выберите аудиофайл. Приложение сразу разберёт его и покажет метаданные:
   длительность, битрейт, частоту дискретизации, раскладку каналов и кодек.
   Если файл не подходит (формат, размер, повреждённый контейнер), появится
   сообщение с причиной — файл не будет добавлен.
4. При желании выберите **обложку**, укажите **название** и **исполнителя**.
   Пустое название подставляется из имени файла.
5. Нажмите **Добавить в библиотеку** — трек появится в списке.
6. Тап по строке открывает плеер; кнопка с корзиной удаляет трек с устройства.

### 1.2. Поддерживаемые форматы и лимиты

| Что | Значение |
| --- | --- |
| Аудио | MP3, WAV, FLAC, AAC |
| Размер аудиофайла | до 50 МБ |
| Обложка | JPG, JPEG, PNG, WEBP |
| Размер обложки | до 8 МБ |
| Превью для прослушивания | 30 секунд |

Правила заданы в одном месте — `AudioImportRules`
(`lib/src/features/library/domain/audio_import_rules.dart`), поэтому подсказка в
интерфейсе и фактическая проверка не могут разойтись.

### 1.3. Плеер

Загруженный трек воспроизводится тем же плеером, что и контент каталога:

- пуск и пауза, перемотка по прогресс-бару, регулировка громкости;
- переключение треков очереди (очередь — все треки вкладки «Загрузки»);
- перемешивание и повтор.

Для MP3, WAV и AAC дополнительно собирается 30-секундное превью — в списке
такой трек помечен чипом `30 с`. FLAC воспроизводится целиком: кадры этого
формата опираются на сквозные контрольные суммы, поэтому произвольный
фрагмент вырезать нельзя.

### 1.4. Где хранятся файлы

Аудио, превью и обложки лежат в приватном каталоге приложения
(`library_files` внутри `getApplicationSupportDirectory()`): на Android —
`/data/user/0/<package>/files`, на iOS — `Library/Application Support`.
Каталог недоступен другим приложениям и не показывается в файловых менеджерах,
публичных ссылок на файлы приложение не создаёт — скачать трек извне нельзя.

Список треков хранится отдельно, в манифесте библиотеки (локальные настройки,
ключ `luma_library_manifest_v1`) — там только ссылки на файлы и метаданные.
При удалении трека удаляются все его файлы.

## 2. Проверки при импорте

| Проверка | Когда выполняется | Что отсекает |
| --- | --- | --- |
| Формат по расширению | до чтения файла | `.ogg`, `.m4a`, файлы без расширения |
| Размер файла | до чтения (по размеру из системы) и повторно перед сохранением | файлы больше 50 МБ, пустые файлы |
| Целостность контейнера | после чтения | обрезанные и повреждённые файлы, несоответствие содержимого расширению |
| Подписи опасного содержимого | после чтения | исполняемые файлы (MZ, ELF, Mach-O), архивы и пакеты (ZIP, dex), скрипты (`#!`), переименованные в аудио |

Импорт выполняется строго по одному файлу (очередь в репозитории): несколько
одновременных добавлений крупных треков не создают пиковой нагрузки на память и
не приводят к гонке за манифестом. Если сохранение прервалось, уже записанные
файлы удаляются, чтобы в каталоге не оставалось мусора.

## 3. Для команды разработки

### 3.1. Файлы

| Файл | Назначение |
| --- | --- |
| `domain/audio_import_rules.dart` | лимиты, списки форматов, валидация формата и размера |
| `domain/audio_metadata.dart` | метаданные трека (кодек, длительность, битрейт, частота, каналы) |
| `domain/imported_audio.dart` | модель импортированного трека, сериализация, `toMediaItem()` |
| `domain/imported_audio_repository.dart` | интерфейс репозитория и `AudioFileCandidate` |
| `domain/audio_import_exception.dart` | ошибка импорта с текстом для пользователя |
| `data/audio_file_inspector.dart` | разбор заголовков контейнеров, проверка целостности, отсечение подмены |
| `data/preview_generator.dart` | сборка 30-секундного превью в исходном контейнере |
| `data/local_imported_audio_repository.dart` | конвейер импорта, манифест библиотеки, очередь |
| `presentation/library_cubit.dart` | состояние раздела «Загрузки» |
| `presentation/widgets/import_sheet.dart` | шторка импорта: выбор файлов, поля, ошибки |
| `core/files/file_storage*.dart` | запись файлов в приватный каталог (IO и заглушка для веба) |

### 3.2. Конвейер импорта

1. `pickAudio()` — системный выбор файла, проверка формата и размера до чтения.
2. `_audioCandidate()` — повторная проверка, разбор контейнера
   (`AudioFileInspector.inspect`) и извлечение метаданных.
3. `importTrack()` — очередь, повторная валидация, сборка превью
   (`PreviewGenerator.build`), запись файлов и манифеста.
4. `load()` — чтение манифеста; записи, файлы которых отсутствуют, отбрасываются.
5. `remove(id)` — удаление записи, аудио, превью и обложки.

### 3.3. Как разбираются форматы

Аудио разбирается по заголовкам контейнеров, без декодирования — это занимает
миллисекунды даже на файле в десятки мегабайт:

- **WAV** — блоки `fmt ` и `data` RIFF; длительность считается по `byteRate`;
- **FLAC** — блок STREAMINFO: частота, каналы, разрядность, общее число сэмплов;
- **MP3** — первый корректный кадр MPEG-1/2/2.5 Layer III (тег ID3v2 пропускается),
  при наличии заголовка Xing/Info берётся точное число кадров;
- **AAC** — поток ADTS: число кадров × 1024 сэмпла.

### 3.4. Как добавить новый формат

1. Добавьте расширение в `AudioImportRules.audioExtensions`.
2. Добавьте ветку разбора в `AudioFileInspector.inspect`.
3. Добавьте ветку в `PreviewGenerator.build` или верните `null` — тогда плеер
   воспроизведёт файл целиком.
4. Добавьте синтетический файл в `test/features/library/audio_fixtures.dart` и
   тесты на разбор и превью.

### 3.5. Тесты

```
flutter test test/features/library
flutter analyze
```

`test/features/library` содержит:

- `audio_import_rules_test.dart` — правила форматов и лимитов, формат размеров;
- `audio_file_inspector_test.dart` — разбор WAV/FLAC/MP3/AAC, отсечение
  замаскированных файлов, подписи метаданных;
- `preview_generator_test.dart` — сборка превью (WAV, MP3, AAC) и отказ для FLAC;
- `audio_fixtures.dart` — синтетические файлы для тестов (без внешних ресурсов).

### 3.6. Ограничения платформы

В браузере (`isSupported == false`) раздел «Загрузки» показывает подсказку:
загрузка и хранение файлов работают только в мобильном приложении, так как
используется файловая система устройства.
